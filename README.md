# ReWear – Clothing Donation & Thrift Platform

📚 Academic Project – Human-Computer Interaction (HCI)

## Overview

ReWear is a UI/UX project developed as part of a university Human-Computer Interaction (HCI) module. The project focuses on designing a user-friendly platform that allows users to discover, buy, sell, and donate clothing while encouraging sustainable fashion practices.

The prototype was designed to provide a modern and intuitive experience inspired by common e-commerce platforms, while incorporating features specifically related to clothing donation, thrift shopping, and sustainable clothing practices.

## Key Features

The prototype includes several features designed to support both buying and selling clothing:
```
🏠 Home Page – Highlights recommended and featured clothing items
🔎 Browse & Search – Allows users to explore available clothing
🎯 Filter & Categories – Helps users narrow down items based on their preferences
❤️ Favourites – Allows users to save items for later
👕 Item Details – Displays information about individual clothing items
➕ Create Listing – Allows users to list clothing for sale or donation
🛒 Cart & Checkout – Provides a shopping flow for purchasing items
👤 User Profile – Allows users to manage their account and listings
💬 Chat / Inbox – Supports communication between users
🚨 Report – Allows users to report potentially inappropriate or problematic listings
```
